# AirAsia Next — Social Listening & Brand Health Dashboard

Interactive executive social listening and brand health dashboard covering all **5 company entities** (`AirAsia (Airline)`, `AirAsia MOVE`, `Santan`, `Asia Digital Engineering (ADE)`, and `Teleport`) across **9 social channels** (`X`, `TikTok`, `XiaoHongShu`, `Instagram`, `Facebook`, `Threads`, `Reddit`, `YouTube`, and `LinkedIn`).

## Live Deployment (GitHub Pages)
This project includes a 100% self-contained static `index.html` at the repository root so it works out-of-the-box on **GitHub Pages** without requiring a server.
